# 🛒 CampusKart

> **An exclusive, peer-to-peer marketplace designed specifically for college students.**

CampusKart simplifies the way students buy and sell essential items on campus. Whether it's textbooks, engineering kits, electronics, or dorm supplies, CampusKart connects buyers and sellers securely and efficiently.

---

## ✨ Key Features

*   **🎓 Exclusive Student Access:** Secure authentication requiring Student ID verification ensures a safe, closed ecosystem.
*   **💬 Seamless Communication:** Direct WhatsApp integration allows buyers and sellers to negotiate and chat instantly.
*   **🤝 Offline Transactions:** Keeping it simple and scam-free—browse online, meet on campus, and pay offline.
*   **⚡ Lightning Fast:** Built with modern web technologies for a smooth, app-like experience.

---

## 🛠️ Tech Stack

*   **Frontend:** Next.js 14, React, Tailwind CSS
*   **Backend:** Next.js API Routes
*   **Database:** MongoDB Atlas
*   **Authentication:** Custom Student ID Verification Workflow
